# Customer Churn Analysis Dashboard – SaiKet Systems

An interactive **Power BI dashboard** developed for **SaiKet Systems** to analyze customer behavior, churn patterns, revenue performance, and service usage.

The project transforms customer data into interactive visualizations, KPIs, and analytical insights to support data-driven decision-making.

## 📊 Dashboard Overview

The dashboard provides insights into:

* Customer churn rate
* Customer retention
* Customer Lifetime Value (CLV)
* Revenue performance
* Customer payment behavior
* Service and subscription usage
* Customer demographics
* Churn patterns and trends

## 🛠️ Technologies

* **Microsoft Power BI**
* **DAX**
* **Data Modeling**
* **Data Visualization**
* **KPI Analysis**

## 📈 Key Features

* Interactive Power BI dashboards
* Dynamic KPIs and measures
* Customer churn analysis
* Revenue and customer value analysis
* Payment behavior analysis
* Service usage analysis
* Interactive filtering and drill-downs
* Business-oriented data visualization

## 🎯 Objectives

The main objectives of this project are to:

1. Identify customer churn patterns.
2. Analyze factors associated with customer attrition.
3. Monitor key customer and revenue KPIs.
4. Understand customer payment and service usage behavior.
5. Provide actionable insights through interactive dashboards.

## 📌 Key Metrics

The dashboard focuses on metrics such as:

* **Churn Rate**
* **Total Customers**
* **Active Customers**
* **Churned Customers**
* **Customer Lifetime Value**
* **Total Revenue**
* **Average Revenue per Customer**
* **Payment Behavior**
* **Service Usage**
